# 🚀 Gestor de Proyectos Colaborativos

![MERN Stack](https://img.shields.io/badge/Stack-MERN-61DAFB?logo=react&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

Plataforma web para la **gestión colaborativa de proyectos** con integración de **Inteligencia Artificial**, diseñada para equipos que buscan optimizar su productividad mediante herramientas innovadoras y automatización inteligente.

---

## 📌 Características Principales

### ✅ Gestión de Proyectos
- Crear, editar y eliminar proyectos.
- Asignación de tareas con fechas límite, prioridad y responsables.
- Tableros Kanban interactivos para visualizar tareas y flujos de trabajo.

### 💬 Comunicación en Tiempo Real
- Chat integrado entre usuarios.
- Notificaciones en tiempo real y alertas automáticas.

### 📊 Panel de Administración
- Dashboard con métricas visuales del estado del proyecto.
- Seguimiento del rendimiento por usuario y proyecto.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **Base de Datos:** MongoDB
- **Estilos:** Tailwind CSS
- **Comunicación:** Socket.IO
- **Control de Versiones:** Git + GitHub

## ⚙️ Instalación y Ejecución

### Requisitos
- Node.js v18 o superior
- MongoDB local o en la nube (Atlas)

### Pasos
```bash
# 1. Clonar el repositorio
git clone https://github.com/usuario/Gestion_Proyectos_Colaborativos.git

# 2. Backend
cd Gestion_Proyectos_Colaborativos/backend
npm install
npm start

# 3. Frontend
cd ../frontend
npm install
npm run dev

# 4. Accede a la app
http://localhost:5173
